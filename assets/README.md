# Assets

Visual assets for the Φ-Plasma-Core repository.

| File | Dimensions | Purpose |
|------|-----------|---------|
| `social-preview.png` | 613 × 567 | Original source image |
| `social-preview-1280x640.png` | 1280 × 640 | GitHub social preview / Twitter card / LinkedIn embed (2:1 aspect ratio, padded with #0A0A0C background) |

## How to set the GitHub social preview

GitHub doesn't expose this via API — must be done in the web UI:

1. Open https://github.com/Prime-007-hash/phi-plasma-core/settings
2. Scroll to **Social preview** (near the bottom of General settings)
3. Click **Edit** → **Upload an image**
4. Choose `assets/social-preview-1280x640.png` (you'll need to download
   it first or upload from your local repo clone)
5. Save

The preview will then appear when the repo is shared on Twitter, LinkedIn,
Slack, Discord, etc. (in places that render OpenGraph metadata).

## What the image represents

A visual of the architecture's central metaphor: a continuous, iridescent
"plasma" (the phase-space token field) flowing across a substrate of
discrete computational elements (the chalkboard/ice). The intersection of
the two — fluid information conservation laid over discrete numerical
computation — is what the architecture embodies.
